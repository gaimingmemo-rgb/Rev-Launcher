## ⚡ Ground-Up Rebuild Features

- **Rebuilt from the Ground Up**: No bloated Electron wrappers or sluggish repackaged Hydra binaries. Re-engineered cleanly in native **PySide6 (Qt6)** with a 60fps responsive UI, instant start time, and ultra-low RAM usage.
- **Hydra Source Engine**: Add any Hydra-compatible source JSON URL or local repository. Comes pre-loaded with verified community sources (SteamRip, FitGirl, DODI, GOG).
- **Interconnected Revision Suite**:
  - **Revision-Web**: Tactical Ad-Shielding P2P Web Browser.
  - **Revision-Ai**: Autonomous Local PC Controller & Intelligence Suite.
  - **Rev-Network Mesh Node**: Distributed P2P telemetry, power calculation, and peer discovery.
- **Rev-Network P2P Connection**: Embeds an active peer node on port `8767` with UDP LAN broadcast (`8769`) and origin sync.
- **Direct & Magnet Downloader**: 1-click magnet forwarding to default torrent clients (qBittorrent) plus background HTTP mirror downloader.
